# ARCILOGGER - Turkish base words that are refused as passwords (build specification 13).
#
# Written by hand for ARCILOGGER (part of the project, same licence as the project; not taken
# from any third-party list). The bundled SecLists list (common-passwords.txt.gz) is
# English-centric; these are words a Turkish-speaking user is likely to build a password from.
# The choice of words is a judgement, not the result of a frequency study: VERIFY ON SITE and
# extend it with words typical for the company (product, department and place names).
#
# Matching (arcilogger_api/auth/passwords.py): the password is case-folded, Turkish diacritics
# are removed (ş=s, ı=i, ğ=g, ü=u, ö=o, ç=c), leetspeak is undone (@/4=a, 0=o, 1/!=i or l, 3=e,
# $/5=s, 7=t) and leading/trailing digits, punctuation and spaces are removed; the password is
# refused when what remains is one of these words ("Galatasaray1905", "Şifre123456!",
# "Y0netici2026!"). Years such as 1903, 1905, 1907 or 1923 need no entry: digits around the
# word are removed before the comparison anyway.
#
# Format: UTF-8, one word per line (Turkish spelling is fine, it is folded when loaded), "#"
# starts a comment line. Words shorter than 4 letters are never compared.
